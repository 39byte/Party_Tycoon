# Popup Asset Guide (`asset/popup/`)

게임 내 주요 이벤트·알림 팝업 상단에 배치할 배너 일러스트 에셋 목록입니다.

## 공통 규격
- **해상도 / 비율**: `1376 × 256` (약 `5.38:1`, 기존 16:9 원본에서 핵심 시선 구간을 세로 1/3 높이로 크롭)
- **포맷**: `.jpg` (JPEG 품질 92, 파일당 약 `65~131 KB`)
- **화풍**: 기존 탭 그림띠(`asset/tab_art/`, 5:1) 및 앱 아이콘(`asset/icon/icon.jpg`)과 동일한 굵은 먹선·셀 셰이딩·다크 네이비/골드/청록 조명 그래픽 노블 화풍
- **텍스트**: 이미지 내 문자·로고·워터마크 없음
