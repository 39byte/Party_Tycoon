# 정당 키우기 (Party Tycoon)

창당준비위원회에서 출발해 정당 등록, 총선·지방선거·대선을 거쳐 **대통령을 배출**하는 턴제 정치 시뮬레이션입니다. 대한민국 정당법·공직선거법·정치자금법의 핵심 규칙을 게임용으로 단순화했습니다.

## 실행

- `index.html`을 브라우저로 열면 됩니다. 설치·빌드·외부 라이브러리 없음, 휴대폰 지원.
- 매 턴 localStorage에 자동 저장. 설정에서 파일 내보내기/불러오기, 크롬·엣지는 저장 폴더 지정 가능.
- 규칙 테스트: `node test.js`

| 파일 | 내용 |
|---|---|
| `index.html` | 화면, 게임 상태, 시뮬레이션, 이벤트 |
| `logic.js` | 순수 규칙: 법정 수치, 선거 일정, 비례 의석·보조금 배분, 기탁금 |
| `art.js` | SVG 그래픽: 시·도 지도, 인물 초상, 탭별 장면 |
| `test.js` | `logic.js` 점검 |

지도는 통계청 2013년 시·도 경계([southkorea-maps](https://github.com/southkorea/southkorea-maps))를 단순화했고, 광주·전남은 전남광주통합특별시로 합쳤습니다(16개 시·도).

## 게임 방법

- **턴:** 1턴 = 1주. 행동력 4(선거운동기간 +1). 활동·교섭마다 행동력 1과 비용을 씁니다. `Space`로 턴 종료, 끝나면 주간 브리핑.
- **창당:** 발기인 200명으로 시작해 시·도 5곳 이상에 당원 1,000명씩 모아 시·도당을 만들고 180일 안에 등록합니다.
- **여론:** 핵심 쟁점은 숨겨져 있어 주간 헤드라인으로 추론해야 합니다. 쟁점을 맞힌 정책·법안이 효과가 큽니다. 화제 지역 소식, 소속 정치인의 자율 행동, 근거 약한 공세 등으로 지지율이 출렁입니다.
- **자금:** 당비·후원금·국고보조금·선거비용 보전으로 벌고 운영비·선거비용 등으로 씁니다.
- **선거:** 총선·지방선거는 2년, 대선은 3년 주기(실제보다 빠름). 선거 전 공천, 준연동형 비례(3% 또는 지역구 5석 봉쇄), 비례 명부 여성 50%·홀수 순번 여성. 선거운동기간엔 유세·광고·TV 토론.
- **사건:** 불법 제안을 받으면 당장 이득이지만 '숨긴 일'로 남아 언젠가 드러날 수 있습니다. 실제 정치사를 닮은 사건과 사회적 이슈(실명 없음)에 입장을 고르면 나중에 여론이 판정합니다.
- **수사·재판:** 고발 → 수사 → 기소 → 1심. 단계마다 대응을 고르고, 유죄면 직 상실도 가능합니다.
- **의회:** 법안 발의(본회의 151표, 거부권 시 재의결 200표), 여야 협상, 대정부 질문, 국정감사·예산·청문회·탄핵.
- **행정:** 광역단체장을 배출하면 별도의 행정 행동력으로 역점사업을 펼칩니다. 지역 현안을 직접 지정하되, 진짜 문제인지는 알 수 없습니다.
- **교섭:** 다른 정당(회동·법안 공조·선거 연대), 원내 의원(친분·법안 협조·이적), 원외 인사(지지 선언·영입). 성공률은 대표 역량, 상대 진영, 관계에 따라 정해집니다.
- **탄핵·조기 대선:** 탄핵이 인용되면 60일 안에 조기 대선. 만 40세 이상 대선 후보감을 미리 준비하세요.

### 게임 오버
- 결성 후 180일 안에 미등록
- 시·도당 요건이 깨진 뒤 90일 안에 회복 못 함
- 4년간 총선·지방선거 불참
- 자금 마이너스 120일 지속

자세한 설명과 지금 할 일은 게임 안 **가이드** 탭에 있습니다. 변경 내역은 `git log`를 보세요.

## 참고

선거권자 수, 보조금 단가, 선거비용 제한액 등은 근사치입니다. 게임 속 정당·인물·사건은 모두 가상이며 실제 법령과 다르게 단순화된 부분이 있습니다.
